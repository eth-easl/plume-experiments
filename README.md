# Plume Experiments

This repository contains everything regarding setup, executing experiments, plotting results, etc. for the [Plume project](https://github.com/eth-easl/plume). Check the [main repository](https://github.com/eth-easl/plume) for more information about Plume.

## Structure

- **`experiments`** contains scripts, configs, and documentation to setup and run Trino and Plume experiments on a cluster of nodes.
- **`results`** contains result data, plots, and the scripts used to create the plots.
- **`tools`** contains other utility tools used for some of the experiments.

*The repo subfolders contain further information.*
